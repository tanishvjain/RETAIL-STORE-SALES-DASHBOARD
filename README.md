# RETAIL-STORE-SALES-DASHBOARD
Project Title & HeadlINE

Retail Store Sales Dashboard
Interactive Power BI dashboard for analyzing retail sales performance and business trends.

2. Purpose

* To provide a clear overview of retail sales performance.
* To analyze sales across products, years, payment methods, order status, and referral sources.
* To make sales data easier to understand through interactive visualizations and filters.

3. Technologies Used

Microsoft Power BI, Microsoft Excel

4. Data Source

Retail Store Sales Dataset containing 1,200 records with order, customer, product, quantity, pricing, payment, shipping, and order-status information.

5. Features & Highlights

* KPI Cards: Sales Year-to-Date, Average Order Value (AOV), and Quantity Sold.
* Interactive Slicers: Product, Payment Method, and Order Status.
* Year-wise Sales Analysis: Visual comparison of sales across different years.
* Product Sales Analysis: Comparison of sales generated by each product.
* Referral Source Analysis: Visualization of sales distribution by referral source.
* Interactive Dashboard: Users can filter the dashboard to explore different aspects of the sales data.
